<h1>🎬 Regular Show API – Personagens</h1>

  <p>
    Projeto acadêmico desenvolvido com <strong>HTML, CSS e JavaScript puro</strong>,
    que consome dados de uma API de personagens do desenho
    <strong>Apenas um Show (Regular Show)</strong> e exibe os personagens
    dinamicamente em formato de cards.
  </p>

  <hr>

  <h2>📌 Objetivo do Projeto</h2>
  <p>
    Demonstrar o consumo de uma API utilizando JavaScript, aplicando
    manipulação do DOM e criação dinâmica de elementos HTML,
    sem o uso de frameworks ou bibliotecas externas.
  </p>

  <p>
    O projeto atende a uma atividade acadêmica com foco em:
  </p>
  <ul>
    <li>Consumo de APIs públicas</li>
    <li>Programação assíncrona com fetch</li>
    <li>Manipulação do DOM</li>
    <li>Criação de interfaces dinâmicas</li>
  </ul>

  <hr>

  <h2>🛠️ Tecnologias Utilizadas</h2>
  <ul>
    <li><strong>HTML5</strong> – Estrutura da aplicação</li>
    <li><strong>CSS3</strong> – Estilização e layout</li>
    <li><strong>JavaScript (Vanilla JS)</strong> – Consumo da API e criação dos cards</li>
    <li><strong>Fetch API</strong> – Requisições HTTP</li>
    <li><strong>Git e GitHub</strong> – Versionamento e publicação</li>
  </ul>

  <hr>

  <h2>🔗 API Utilizada</h2>
  <p>
    API de personagens do desenho <strong>Apenas um Show</strong> (Própria),
    com respostas no formato <strong>JSON</strong>.
  </p>

  <p>
    Características da API:
  </p>
  <ul>
    <li>Requisições do tipo <strong>GET</strong></li>
    <li>Não exige autenticação (token)</li>
    <li>Dados retornados em JSON</li>
  </ul>

  <p>Exemplo de resposta:</p>
  <pre>
[
  {
    "name": "Mordecai",
    "species": "Gaio-Azul",
    "image": "url_da_imagem",
    "description": "Um dos personagens principais do desenho"
  }
]
  </pre>

  <hr>

  <h2>⚙️ Funcionalidades</h2>
  <ul>
    <li>Consumo da API usando <code>fetch()</code></li>
    <li>Criação dinâmica de cards via JavaScript</li>
    <li>Exibição de nome, imagem e descrição dos personagens</li>
    <li>Layout responsivo e temático</li>
  </ul>

  <hr>
